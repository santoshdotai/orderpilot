# OrderPilot - Best Solution Architecture

> **Project Name:** OrderPilot
> **Project Type:** AI-Powered WhatsApp Sales & Order Management Platform
> **Final Goal:** An AI Sales Operating System for WhatsApp-based businesses that automates order management, quotation, customer communication, follow-ups, and sales workflow through AI-powered WhatsApp operations.

---

## 1. Recommended Technology Stack (Best Choice)

This is the **single best, production-ready stack** chosen from the options in the Readme. It balances speed of delivery (Lovable prototype) with long-term scale (Vercel + Supabase + n8n).

| Layer | Recommended Choice | Why This Is Best |
|---|---|---|
| **Frontend (UI Generation)** | Lovable (initial prototype) | Fastest way to generate a working React + Tailwind dashboard UI from prompts. |
| **Frontend (Production)** | React + Vite + Tailwind CSS | Industry standard, fast HMR, Lovable export is compatible. |
| **Backend / DB** | Supabase (PostgreSQL) | Managed Postgres + Auth + RLS + Storage + Realtime in one. |
| **Auth & Security** | Supabase Auth + Row Level Security (RLS) | Built-in JWT auth; RLS protects multi-tenant data at the DB layer. |
| **WhatsApp Channel** | Interakt WhatsApp Business API | Official, reliable, supports text + media + voice notes. |
| **AI - Text Understanding** | Google Gemini (primary) with OpenAI GPT-4o (fallback) | Gemini is cost-efficient for extraction; OpenAI as redundancy. |
| **AI - Voice Transcription** | OpenAI Whisper API (or Gemini multimodal) | Best-in-class accuracy on multilingual voice notes. |
| **Automation Engine** | n8n (self-hosted on Railway/Render, or n8n Cloud) | Visual workflow builder for Interakt ↔ Supabase ↔ AI orchestration. |
| **Spreadsheet Layer (Sales-Ops UX)** | Google Sheets (via Google Sheets API + n8n Sheets node) | Sales team already lives in spreadsheets — they edit the product catalog, view quotations/orders/invoices, and manage stock without ever opening the dashboard. Two-way sync keeps Supabase as source of truth. |
| **Invoicing** | Supabase `invoices` + `invoice_items` + PDF generated by an Edge Function and stored in Supabase Storage | Native invoicing module — auto-generated from approved quotations, sent via Interakt WhatsApp as a PDF link, status tracked (draft → sent → paid → overdue), and mirrored to Google Sheets for finance. |
| **Deployment (Phase 1)** | Lovable hosted preview | Zero-config to demo to stakeholders. |
| **Deployment (Phase 2)** | Vercel (frontend) + Supabase (backend) + Railway (n8n) | Best DX, edge functions, zero ops. |

## 2. Original Core Workflow (Preserved from Readme)

1. Customer sends WhatsApp message or voice note.
2. Interakt WhatsApp Business API receives the message.
3. Interakt webhook forwards message data to OrderPilot AI backend.
4. Message is stored in Supabase database.
5. If voice note → audio is transcribed using AI.
6. Gemini AI / OpenAI processes the message.
7. AI extracts products, quantities, urgency, and delivery details.
8. n8n automation workflows execute business logic.
9. Quotation draft is generated automatically (priced against the product catalog, which is editable from Google Sheets).
10. Sales team reviews and approves quotation.
11. On approval → **Invoice is auto-generated** (PDF in Supabase Storage), sent to the customer via WhatsApp, and mirrored to Google Sheets for finance.
12. Dashboard updates analytics, leads, follow-up reminders, **and invoice payment status**.
13. Google Sheets stays continuously in sync (two-way) for product catalog, quotations, orders, and invoices — so non-technical sales/finance staff can work in the spreadsheet they already use.

## 3. Use Cases Covered (Preserved from Readme)

- Customer sends order through WhatsApp text or voice note.
- AI extracts products and quantities automatically.
- Quotations are generated instantly.
- Sales team responds faster.
- AI follow-ups prevent missed opportunities.
- Dashboard provides business insights and tracking.
- **Invoices are auto-generated** from approved quotations, delivered as a PDF over WhatsApp, with payment status tracked end-to-end (draft → sent → paid → overdue).
- **Google Sheets is a first-class workspace**: the sales team manages the product catalog (price, stock) directly in a sheet, and every quotation / order / invoice mirrors to Sheets so finance and non-technical users never have to log into the dashboard.

**Reading the diagram:**

- **Google Sheets** sits beside Supabase as the spreadsheet-friendly UX surface. n8n keeps Supabase ↔ Sheets in two-way sync so non-technical users can edit the product catalog, watch quotations roll in, and reconcile invoice payments without ever opening the React dashboard.
- **Invoice Engine** is a Supabase Edge Function that, on quotation approval, materialises an `invoices` row + line items, renders a PDF, uploads to Supabase Storage, and hands the public link to n8n for Interakt delivery + Sheets mirroring.

### 4.2 Database (Supabase / Postgres) - Core Tables

| Table | Purpose |
|---|---|
| `customers` | WhatsApp phone, name, language, segment |
| `messages` | Raw inbound/outbound message log (text + media url) |
| `transcriptions` | Voice-note → text results |
| `ai_extractions` | Products, qty, urgency, delivery extracted by AI |
| `products` | Product catalog (sku, name, price, stock) |
| `quotations` | Draft + approved quotations |
| `quotation_items` | Line items linked to a quotation |
| `orders` | Confirmed orders |
| `invoices` | Auto-generated invoices (number, customer, totals, tax, status: draft/sent/paid/overdue, due_date, pdf_url) |
| `invoice_items` | Invoice line items (product, qty, unit_price, tax, line_total) linked to an invoice |
| `payments` | Recorded payments against invoices (amount, method, reference, paid_at) |
| `follow_ups` | Scheduled reminders / nudges (also used for invoice payment reminders) |
| `sheet_sync_log` | Tracks last sync timestamp + row hashes per Google Sheet to avoid loops |
| `users` | Sales team accounts (Supabase Auth) |
| `audit_log` | Who approved/edited what, when |

All tables protected by **Row Level Security (RLS)** so each tenant/sales rep only sees their own data.

### 4.3 Why This Beats the Alternatives

- **Supabase over raw Postgres + custom auth:** Saves weeks; Auth, Storage, RLS, Realtime out of the box.
- **n8n over hard-coded backend logic:** Non-developers can then follow-up rules, quotation templates, escalation paths.
- **Gemini primary + OpenAI fallback:** Cost-optimized with redundancy on AI outages.
- **Vercel over Netlify for Phase 2:** Better support for React Server Components and edge runtime if needed.
- **Lovable for Phase 1:** Cuts UI scaffolding time from days to hours.
